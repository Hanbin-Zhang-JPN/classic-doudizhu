# 三人局 · 经典斗地主

**[点击这里，直接开始游玩](https://hanbin-zhang-jpn.github.io/classic-doudizhu/)**

一副 54 张扑克牌，你与两位 AI 对战。地主独自对抗两名合作的农民。不需要注册、下载或安装，用 MacBook Air M3、其他电脑或手机的现代浏览器打开上面的地址即可。

所有牌局和 AI 计算在浏览器本地运行，不上传手牌，不涉及现金、付费筹码或奖励。刷新页面会重新开桌，不保存游戏进度。

## 怎么玩

1. 轮到你时选择「不叫」或 1、2、3 分，叫分必须高于已有最高分。
2. 最高叫分者拿到公开的三张底牌成为地主，地主先出牌。
3. 单击手牌选中 / 取消，点击「出牌」。可以选择多张。
4. 「提示」循环选择合法组合，不替你打出；「清空」取消选择；接牌时可以「不出」。
5. 选好牌后也可按 Enter 出牌，按 Escape 清空。对话框内不会触发出牌快捷键。
6. 地主先出完则地主胜；任一农民先出完则两名农民一起胜。每局结束可看结算及三家剩余牌。

## 本桌规则

采用经典**叫分制**，不是「抢地主再加倍」模式。首局你先叫分，其后轮换起叫者；每人仅叫一次，叫 3 分立即确定地主。三家都不叫时重新洗牌并轮换起叫者。

每人 17 张，三张底牌给地主，地主最终 20 张，底牌全局明示。出牌顺序：你 → 川叔 → 蓉姐 → 你。

牌点大小：大王 > 小王 > 2 > A > K > Q > J > 10 > 9 > … > 3；花色不比大小。

| 牌型 | 条件 / 示例 |
| --- | --- |
| 单张、对子、三张 | 3、33、333 |
| 三带一、三带一对 | 3334、33344 |
| 顺子 | 至少五张，34567 |
| 连对 | 至少三对，334455 |
| 飞机（不带） | 至少两组连续三张，333444 |
| 飞机带单 | 每组三张附带一张单牌，33344456 |
| 飞机带对 | 每组三张附带一个对子，3334445566 |
| 四带二单 | 四张同牌加两张单牌，333345 |
| 四带两对 | 四张同牌加两个对子，33334455 |
| 炸弹 | 四张同点数，3333 |
| 王炸 / 火箭 | 大小王同时打出 |

顺子、连对及飞机主体只能从 3 连到 A，不能包含 2 或王。附带牌不能与主体同点数。

**本桌的明确附带牌限制：**飞机单翼和四带二单须点数各不相同，不允许一对充当两张单翼，也不允许大小王一起当单翼。对子翼须是不同点数的对子。地方或平台版本可能不同，本游戏以这里列明的条件为准。

普通牌型必须同类型、同张数、同连续组数，比较主体点数（连牌比较最高点数）。三带、四带、飞机的附带牌不参与大小比较。

炸弹压全部普通牌型，较大的炸弹压较小的炸弹；王炸最大。**四带二不是炸弹。**两名玩家连续不出后，上一次出牌者重新领出，可换任意合法牌型；新一轮领出不能不出。

### 积分

- 底分 = 地主叫分（1～3 分）。
- 每出一个炸弹或王炸，倍数 ×2。
- 地主胜且两名农民都没出过牌为春天；农民胜且地主只出过一手为反春天，再 ×2。
- 每位农民输赢 = 底分 × 最终倍数；地主输赢为两倍。
- 农民胜时两名农民都加分、地主扣两份；地主胜时相反，积分总和为零。
- 不启用额外加倍、明牌、癞子、底牌奖励、计时强制托管。

基础发牌、叫分与牌型参考 [JJ 帮助中心的斗地主规则](https://www.jj.cn/news/320/20110920103700018196.shtml)。无人叫分、附带牌与积分的细节以本项目上述明确桌规为准，不完全等同于该平台比赛规则。

## AI 与画面

- AI 每次独立随机思考 0.5～1.5 秒。
- AI 不读取对手暗牌，只使用自己的手牌、当前出牌、阵营与公开余牌数；叫分只评估自己的手牌。
- 农民 AI 通常不压队友；可直接出完获胜时例外。领出时会考虑队友报单，对手报单时优先避免送单张。
- AI 为启发式策略，不是专业竞技级或保证最优的求解器。
- J、Q、K 使用原甩二项目的三张原创人物画像；本项目不需要联网加载第三方图片或字体。

## 离线运行

下载本仓库 ZIP，解压后双击 **index.html**。不需要 Node.js、安装依赖或启动服务器，可完全离线游玩。

## 开发与验证

原生 HTML / CSS / JavaScript，没有构建步骤。`rules.js` 包含牌型、压牌、叫分、对局及 AI；`app.js` 管理显示、交互与随机 AI 定时。

已安装 Node.js 的开发者可运行：

```sh
node --test tests/rules.test.js
node --check app.js
```

测试覆盖所有支持牌型、合法性、炸弹、叫分、连续不出、春天、反春天、合作 AI、不窥牌、出牌枚举，以及 100 局完整 AI 模拟。每局逐步检验 54 张实体牌守恒与零和结算。

GitHub Pages 从 `main` 分支根目录发布。无需服务器端和密钥。MIT 许可，见 [LICENSE](LICENSE)。
